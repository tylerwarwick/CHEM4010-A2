# CHEM4010 – Chemical Industry Poster

This repository contains my scientific poster for **CHEM4010 (Chemical Industry)**.

The poster examines the chemistry, synthesis, efficacy, and commercial context of ketamine as an antidepressant, with particular emphasis on stereospecific synthesis.
